# mcp-upload

File uploads for MCP servers, using short-lived upload tickets.

MCP tool calls carry JSON only. There is no file input type, and a file encoded as
base64 inside a tool argument has to be generated by the model one token at a time.
That does not complete for anything larger than a small image, and the reference
Python SDK refuses request bodies over 4 MiB in any case.

This library gives an MCP server a working upload path that needs no change to the
protocol. A tool hands back a short-lived, single-use upload URL. The bytes travel
over ordinary HTTPS outside the protocol, straight through to your existing backend.
Only a small reference goes through MCP.
